# 01 · 概览：背景、目标、范围

## 1. 背景

沃泰能源的储能产品（阳台储能、户用储能、工商业储能、EMS/BMS）销往欧洲多国。售后咨询有三个结构性特征：

| 特征 | 表现 | 后果 |
|---|---|---|
| 语言分散 | 德/荷/西/英/中混用 | 客服语种覆盖不足，错误理解频发 |
| 时区错位 | 客户在欧洲白天提问，中国团队夜间无人 | 首响时长不可控，客户流失 |
| 重复度高 | 参数、安装步骤、故障码、保修条款 | 八成问题答案已在公开手册里，人力被低价值咨询吃掉 |

### 1.1 为什么是 Agent，不是 FAQ

真实问法是组合式的：

> "我装的 600W 微逆报 E03，并网点电压 240V，保修还在期内吗？"

一句话横跨**故障码表 + 安装手册 + 保修条款**三份文档。关键词匹配必然答错。

Agent 的价值不在"能聊天"，在**多步工具调用 + 引用溯源**。而引用可核查是这个产品能被企业放进客户现场的唯一理由：答错要能被追责，追责要能点回原文。

### 1.2 非目标（说清楚免得跑偏）

- 不做全自动客服。人工兜底是产品的一部分，不是缺陷。
- 不做多模态。本期图片只存不认。
- 不做多 agent 协作。单 agent + 7 个工具足够，多 agent 只增加不确定性。

## 2. 目标

### 2.1 北极星指标

**AI 独立解决率** = 满足以下全部条件的会话数 ÷ 总会话数

- 24 小时窗口内无坐席回复
- 用户未点 👎
- 未产生 `user_request` 类工单

目标：**≥ 60%**（上线 4 周后评估）

### 2.2 本期（Day-1 交付）验收指标

| 指标 | 定义（可测，无歧义） | 目标 |
|---|---|---|
| 引用正确率 | 答案中每个 `[n]`，n ∈ 本轮 `kb_search` 候选编号集合 的比例 | ≥ 85% |
| 拒答准确率 | `qa_gold.should_refuse=true` 的题中，输出固定话术且新建 1 条工单的比例 | ≥ 90% |
| 检索命中 hit@5 | 召回 top5 chunk 中任一 `doc_id == qa_gold.expect_doc_id` 的题占比 | ≥ 70% |
| 首字延迟 | 发送 → SSE 第一个 `delta` | P95 < 3s |
| 单轮延迟 | 发送 → `done` | P95 < 8s |
| 故障码直查 | 输入 → 结果卡渲染 | P95 < 1s |
| 单会话成本 | `conversations.total_cost_usd` ÷ 会话数（按 6 轮/会话） | < $0.03 |
| 闭环 | 02/03 两章的功能全部走通 | 100% |

> 指标口径说明：v1.0 的"< $0.01/会话"是按单轮 8k in / 1k out 算的算术错误。六轮会话累计约 in 30k / out 3k，按 DeepSeek Flash（$0.3/M in、$1.2/M out）约 $0.0126。上限放到 $0.03 留余量。

### 2.3 三个月目标（非本期）

- 自助解决率 ≥ 60%，转人工率从 100% 降到 ≤ 35%
- 平均首响从小时级降到 < 10s
- 知识库覆盖：Top 50 未命中问题清零

## 5. 关键场景脚本

### S1 · 安装商现场排障（P1，德语）

```
14:20 配电箱旁。手机打开 /，界面已是德语（浏览器语言）。
输入 "E03"
→ 1.2s：故障码卡（含义 / 严重度 / 三步处理 / 引用 安装手册 p.12）
处理完仍报错 → 点「转人工」→ 填邮箱 → 拿到 WT-2026-0031
当晚 22:40 坐席端队列出现该单，SLA 剩 1h20m
```

### S2 · 业主问保修（P2，荷兰语）

```
"Zit de batterij ook in de 10 jaar garantie?"
→ 检索命中保修条款 → 荷兰语回答 + 角标 [1]
点 [1] → 底部抽屉：保修条款 p.3 原文，关键词高亮
不满意 → 👎 → 自动进未命中池
```

### S3 · 坐席处理拒答单（P3，中文）

```
队列：WT-2026-0031，reason=no_citation，SLA 2h14m
点开：完整对话 + AI 当时的回答
右侧 AI 面板：候选答复（带 2 条引用）
「采纳」→ 编辑 → 发送 → 关单
顺手「转 FAQ 草稿」→ 审批 → 下次同类问题 AI 能直接答
```

### S4 · 越界提问（任意语言）

```
"Kunnen jullie 20% korting geven?"
→ 不检索、不编造 → 固定话术（5 语）
→ 自动建单 reason=out_of_scope
→ 进未命中池
```

### S5 · 多轮追问（P1，德语）

```
Q1: "Welcher Wechselrichter ist im Set enthalten?"
A1: 型号 + 引用
Q2: "Und wie viel Watt?"        ← 省略主语，指代上文
A2: 600W + 引用
```

> S5 是检索引擎的真实考验：Q2 没有实词，必须靠多轮上下文。04 章的会话策略必须支持，否则第二轮必错。

## 6. 术语

| 术语 | 含义 |
|---|---|
| Session | Pi 的一次对话上下文载体 `AgentSession` |
| Extension | Pi 的 TypeScript 扩展模块，注册工具与事件钩子 |
| Skill | `SKILL.md` 形式的按需加载指令包（Agent Skills 规范） |
| RRF | Reciprocal Rank Fusion，融合向量与全文两路排序 |
| no_citation | 本轮无任何检索证据，按规则必须拒答并建单 |
| 独立解决 | 24h 内无坐席介入、无 👎、无 user_request 工单 |
