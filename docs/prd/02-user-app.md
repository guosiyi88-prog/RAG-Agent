# 02 · 用户端规格（9:16 竖屏）

## 1. 画布

| 项 | 值 |
|---|---|
| 比例 | **9:16 竖屏** |
| 设计基线 | 390 × 844（iPhone 14 / Pixel 7 之间） |
| 最小支持 | 360 × 640（老 Android） |
| 桌面表现 | 居中 9:16 手机框，两侧 `#0F172A`，框外不响应点击 |
| 方向 | 只支持竖屏；横屏显示"请竖屏使用"（不做横屏布局） |

```css
.phone {
  width:  min(100vw, calc(100dvh * 9 / 16));
  height: min(100dvh, calc(100vw * 16 / 9));
  aspect-ratio: 9 / 16;
  margin-inline: auto;
  overflow: hidden;
  position: relative;
  padding-top: env(safe-area-inset-top);
  padding-bottom: env(safe-area-inset-bottom);
}
```

硬性禁止：页面级横向滚动；`user-scalable=no`；`100vh`（用 `100dvh`）；`position:fixed` 顶键盘。

## 2. 设计令牌

```css
:root {
  /* 间距 4/8 栅格 */
  --s1:4px; --s2:8px; --s3:12px; --s4:16px; --s6:24px; --s8:32px; --s12:48px;
  /* 圆角 */
  --r-sm:8px; --r-md:12px; --r-lg:16px; --r-xl:24px; --r-full:999px;
  /* 字号 */
  --t-cap:12px; --t-sm:14px; --t-body:16px; --t-title:20px; --t-h2:24px;
  /* 层级 */
  --z-base:0; --z-sticky:10; --z-overlay:20; --z-sheet:40; --z-toast:100;
  /* 动效 */
  --ease-out:cubic-bezier(.16,1,.3,1);
  --dur-fast:150ms; --dur-base:220ms; --dur-slow:320ms;
  /* 尺寸 */
  --header-h:56px; --tabbar-h:56px; --composer-h:64px;
}
```

### 2.1 色彩

| 令牌 | Light | Dark | 用途 |
|---|---|---|---|
| `--primary` | `#F97316` | `#FB923C` | 主按钮、当前 tab |
| `--on-primary` | `#0F172A` | `#0F172A` | 主色上文字（对比 4.6:1） |
| `--accent` | `#22C55E` | `#4ADE80` | 成功、在线 |
| `--bg` | `#FFFFFF` | `#0F172A` | 页面底 |
| `--surface` | `#F8FAFC` | `#1F2937` | 气泡、卡片 |
| `--text` | `#0F172A` | `#F8FAFC` | 正文 |
| `--muted` | `#64748B` | `#94A3B8` | 次要信息（对比 ≥4.5:1） |
| `--border` | `#E2E8F0` | `#374151` | 分割线 |
| `--danger` | `#EF4444` | `#F87171` | 拒答、错误 |
| `--warn` | `#F59E0B` | `#FBBF24` | 降级提示 |

深色切换：`<html data-theme="dark">`，跟随系统 `prefers-color-scheme`，用户可在「我的」覆盖。

### 2.2 字体

| 用途 | 字体栈 |
|---|---|
| 标题 | `Space Grotesk` |
| 正文 | `Noto Sans SC, system-ui, -apple-system, sans-serif` |
| 数字/故障码/单号 | `Space Grotesk` + `font-variant-numeric: tabular-nums` |

只加载 `Space Grotesk` 的 500/700 两个字重，`font-display: swap`。

## 5. U-P1 对话页

### 布局与组件

| 区域 | 高度 | 组件 |
|---|---|---|
| 顶栏 | 56px | 返回、标题、语言 pill、⋮（清空/导出） |
| 消息流 | flex | 气泡列表，`padding-bottom: var(--composer-h)` |
| 状态条 | 24px | 「正在查资料…」/「正在输入…」 |
| Composer | 64px | ＋按钮、输入框、发送按钮 |

### 气泡规格

| 项 | 助手 | 用户 |
|---|---|---|
| 对齐 | 左 | 右 |
| 底色 | `--surface` | `--primary` |
| 文字 | `--text` | `--on-primary` |
| 圆角 | `--r-lg` | `--r-lg` |
| 最大宽 | 80% | 80% |
| 内边距 | 12px 14px | 12px 14px |
| 行高 | 1.55 | 1.55 |

### 引用角标

- 视觉 18×18，`--primary` 描边，字号 11
- 命中区用 `::after` 扩到 **44×44**
- `aria-label="引用 n，查看原文"`
- 多个角标连排，间距 4px

### 交互规则

| 场景 | 行为 |
|---|---|
| 用户连发两条 | 第二条走 `steer`，插入当前轮；UI 显示"已插入" |
| 流式中点发送 | 按钮置灰 400ms，防连点 |
| 网络断开 | 顶部黄条「网络已断开，恢复后自动重试」，`--warn` |
| 超 8s 无首字 | 状态条改为「仍在处理，可继续等待或转人工」+ 转人工按钮 |
| 拒答 | 气泡底色转 `--surface` + 边框 `--danger` 20%，下方追加"已创建工单 WT-…"小卡 |
| 清空会话 | ⋮ → 二次确认 → 新建会话（旧会话仍在历史里） |

### 状态矩阵

| 状态 | 表现 |
|---|---|
| loading | 骨架气泡 3 条，120ms 淡入 |
| streaming | 光标块 `▍` 跟随文字尾 |
| empty | 不出现（首屏替代） |
| error | 气泡内红色文字 + 重试按钮 |
| refused | 固定话术 + 工单小卡 |
| offline | 顶部黄条 |

### 验收

- [ ] 德语提问德语作答，UI 同步德语
- [ ] 每条助手消息 ≥1 角标
- [ ] 内容宽度不超 80%，无横向滚动
- [ ] 键盘弹出时 composer 贴键盘，消息流不被遮挡

## 6. U-P2 引用抽屉

### 规格

| 项 | 值 |
|---|---|
| 类型 | Bottom Sheet（非 Modal） |
| 高度 | 内容自适应，`max-height: 70%` |
| 蒙层 | `rgba(15,23,42,.5)` |
| 入场 | 从底部滑入 220ms `--ease-out` |
| 出场 | 下滑 160ms（比入场快 30%） |
| 关闭 | 下滑 >96px ／ 点蒙层 ／ Esc |
| 焦点 | 打开移到抽屉标题，关闭回到角标 |

### 内容结构

```
┌─────────────────────────────┐
│           ────              │ 拖拽把手 36×4
│  引用 1 / 3            [×]   │
│ ┌─────────────────────────┐ │
│ │ 阳台储能 600W 安装手册    │ │ 文档名 --t-title
│ │ 第 12 页 · 2026-03 版     │ │ --t-sm --muted
│ │                          │ │
│ │ "并网点电压应在 195–253V  │ │ 原文 ≤300 字
│ │  之间，超出范围时逆变器   │ │ 关键词高亮 --warn bg
│ │  将报 E03 并停机..."      │ │
│ └─────────────────────────┘ │
│  ◀ 上一条     下一条 ▶       │ 多引用时出现
│ [ 打开完整文档 ]   [ 关闭 ]   │
└─────────────────────────────┘
```

### 规则

- 原文超 300 字截断，末尾「…展开」→ 展开后内部滚动
- 「打开完整文档」→ 新标签打开 MinIO 签名 URL（PDF 定位到页）
- 无引用时抽屉不出现（角标不渲染）

### 验收

- [ ] 下滑关闭有跟手动画
- [ ] 蒙层 ≥40% 黑
- [ ] 键盘 Esc 可关
- [ ] 关闭后焦点回到原角标

## 10. 五语文案方案（U9）

### 规模

| 类别 | 条数 | 说明 |
|---|---|---|
| 通用 UI | 62 | 按钮、状态、提示、空态、错误 |
| 拒答话术 | 5 | 每种语言 1 条长话术 |
| 快捷问题 | 12 | 6 卡 × 2 个变体（标题 + 问题） |
| 故障码页 | 8 | |
| 工单页 | 15 | |
| 我的 | 18 | |
| 元信息 | 20 | 严重度、状态徽章等 |
| **合计** | **140 条 × 5 语 = 700 条** | |

### 实现

- 单一 `i18n.json`，结构 `{ "zh": { "chat.send": "发送", ... }, "de": {...} }`
- 缺失 key 回落到 `en`，仍缺失显示 key 本身（开发期可见）
- 禁止在 JSX/HTML 里硬编码任何用户可见文字

### 生成与校验

1. 以中文为主源，LLM 一次生成 de/nl/es/en 四份
2. 术语表锁定：`inverter / Wechselrichter / omvormer / inversor`、`warranty / Garantie / garantie / garantía`
3. 抽样人工校对：德语全量（最高频市场），荷兰语/西语各抽 20%
4. 校验脚本：key 集合完全一致、无空值、无超长（>2× 中文长度告警）

### 验收

- [ ] 5 语齐全，无缺失 key
- [ ] 切换语言后整页文案变化，无需刷新
- [ ] 无文字溢出/截断（德语长词是主要风险）

## 11. 无障碍

| 项 | 要求 |
|---|---|
| 对比度 | 正文 ≥4.5:1；角标等小元素 ≥4.5:1 |
| 触摸目标 | ≥44×44（角标、⋮、卡片整块可点） |
| 焦点环 | 2px `--primary`，`offset 2px` |
| 屏幕阅读器 | 新消息用 `aria-live="polite"`；角标有 `aria-label` |
| 动效 | `prefers-reduced-motion: reduce` → 全部改为淡入无位移 |
| 动态字号 | 支持系统字号放大到 130% 不破版 |
| 表单 | 邮箱输入 `type=email` `inputmode=email`，错误就近显示 |
