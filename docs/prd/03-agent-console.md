# 03 · 坐席端规格（16:9 桌面）

## 1. 画布

| 项 | 值 |
|---|---|
| 比例 | **16:9 横屏** |
| 设计基线 | 1440 × 810 |
| 最小支持 | 1280 × 720（低于此提示"请放大窗口"） |
| 最大内容宽 | 无（表格类铺满，正文类限 760px 行宽） |
| 滚动 | 主区纵向滚动；左侧导航固定不滚 |

### 骨架尺寸

| 区域 | 尺寸 |
|---|---|
| 顶栏 | 高 56px，全宽 |
| 左侧导航 | 宽 240px，从顶栏下到页底 |
| 主区 | `flex: 1`，最小 560px |
| 右面板（详情页） | 宽 380px，可折叠 |
| 工单列表列 | 宽 320px |

| 令牌 | 值 | 用途 |

| `--primary` | `#0F172A` | 顶栏、导航底 |
| `--cta` | `#0369A1` | 主操作按钮 |
| `--bg` | `#F8FAFC` | 工作区底 |
| `--surface` | `#FFFFFF` | 卡片、表格 |
| `--border` | `#E2E8F0` | 表格线、分割线 |
| `--text` | `#0F172A` | 正文 |
| `--muted` | `#64748B` | 次要 |
| `--st-open` | `#F59E0B` | 待处理 |
| `--st-claimed` | `#0369A1` | 处理中 |
| `--st-closed` | `#22C55E` | 已关闭 |

只做浅色主题（坐席端不做深色，减少测试面）。

### 布局

```
┌──────────┬──────────────────────────────────────────────────────────┐
│ 沃泰 客服台│ 工单                                      张伟 ▾    ⚙    │ 56
├──────────┼──────────────────────────────────────────────────────────┤

│  知识库   │ ┌──────────────────────────────────────────────────────┐ │
│  未命中 5 │ │ 单号        │ 摘要              │ 原因        │ SLA    │ │ 表头 40
│  SOP      │ ├────────────┼──────────────────┼────────────┼────────┤ │
│  看板     │ │WT-2026-0031│ E03 反复出现      │ ⚠ 无引用    │ 2h14m  │ │ 行 56
│          │ │ 德 · 14:20 │ 张伟              │ out_of…    │ ●红    │ │
│ 240      │ ├────────────┼──────────────────┼────────────┼────────┤ │
│          │ │WT-2026-0030│ 保修是否含电池    │ ⚠ 无引用    │ 5h02m  │ │
│          │ └────────────┴──────────────────┴────────────┴────────┘ │
└──────────┴──────────────────────────────────────────────────────────┘
```

### 表格列定义

| 列 | 字段 | 宽 | 格式 |
|---|---|---|---|
| 单号 | `tickets.no` | 140 | `Fira Code`，可复制 |
| 摘要 | `tickets.question[:40]` | flex | 单行省略，hover 显示全文 |
| 语言 | `conversations.lang` | 60 | 大写两字母 |
| 原因 | `tickets.reason` | 120 | 徽章，见下表 |
| 指派 | `tickets.assignee` | 80 | 无则显示"—" |
| SLA | `due_at - now()` | 100 | 倒计时，<1h 转 `--st-sla` 加粗 |
| 创建 | `created_at` | 90 | `MM-DD HH:mm` |

### 原因徽章映射

| reason | 文案 | 颜色 |
|---|---|---|
| `no_citation` | 无引用 | `--st-open` |
| `out_of_scope` | 越界 | `#8B5CF6` |
| `low_conf` | 低置信 | `--st-open` |
| `user_request` | 用户要求 | `--st-claimed` |

### 交互

| 场景 | 行为 |
|---|---|
| 点行 | 打开 A-P2，URL 变 `#/ticket/{id}`（可分享） |
| 排序 | 默认 SLA 升序；点表头切换，`aria-sort` 标注 |
| 新单到达 | 5s 轮询；新单在顶部闪一次 `--st-open` 边框 300ms |
| 空列表 | 「暂无工单，AI 正在自助处理」+ 说明 |
| 无权限 | 不出现（固定 token 全覆盖） |

### 验收

- [ ] 新单 5s 内出现
- [ ] 倒计时等宽不抖动
- [ ] 1440×810 一屏可见 ≥10 行

## 5. A-P2 工单详情（三栏）

```
┌──────────┬──────────────┬────────────────────────────┬──────────────────┐
│ 导航      │ 队列 320      │ 会话主区 flex               │ AI 助手 380       │
│          │ ┌──────────┐ │ ┌────────────────────────┐ │ ┌──────────────┐ │
│          │ │WT-0031 ● │ │ │ 单号 WT-2026-0031 [复制]│ │ │ 候选答复      │ │
│          │ │out_of    │ │ │ 德语 · 400W 微逆        │ │ │ ....         │ │
│          │ │2h14m     │ │ │ SLA 2h14m [认领]        │ │ │ 保修 10 年[1] │ │
│          │ └──────────┘ │ ├────────────────────────┤ │ └──────────────┘ │
│          │              │ │ 用户: Wechselrichter... │ │ 引用             │
│          │              │ │ AI: E03 表示...  [1]    │ │ [1] 手册 p.12    │
│          │              │ │ ⚠ 无检索证据，已拒答     │ │ [2] 保修 p.3     │
│          │              │ ├────────────────────────┤ │                  │
│          │              │ │ 坐席回复框              │ │ [采纳][改写][译] │
│          │              │ │                        │ │                  │
│          │              │ │ [发送] [转L2] [关单]     │ │ 快捷             │
│          │              │ └────────────────────────┘ │ [开单][FAQ][导出]│
└──────────┴──────────────┴────────────────────────────┴──────────────────┘
```

### 中间区：对话回放

| 元素 | 规格 |
|---|---|
| 用户消息 | 左对齐，`--surface` 底，最大宽 720px |
| AI 消息 | 左对齐，白底 + 左侧 3px `--cta` 竖线，角标可点开原文 |
| 拒答标记 | AI 消息下方一行 `--st-open` 文字："⚠ 本轮无检索证据" |
| 工具轨迹 | 折叠块「本轮调用 kb_search · 420ms」，默认收起 |
| 时间轴 | 每条显示 `HH:mm`，跨天显示日期分隔 |

### 右侧 AI 面板

| 区块 | 内容 | 行为 |
|---|---|---|
| 候选答复 | 基于知识库生成，带角标 | 「采纳」填入回复框；「改写」按坐席指令重生成；「译」翻成工单语言 |
| 引用列表 | 文档名 + 页码 + 片段 | 点开 Modal 看原文 |
| 快捷操作 | 开单 / 转 FAQ 草稿 / 导出会话 HTML / 转 L2 | 各自弹确认 |

**约束**：候选答复必须**新建 session** 生成，不复用用户会话（避免上下文污染）。生成耗时约 2–4s，期间显示骨架。

### 回复框

| 项 | 规格 |
|---|---|
| 高度 | 初始 120px，可拖高到 320px |
| 语言 | 默认工单语言，可切换（切换时若已有内容，提示"是否翻译"） |
| 发送 | `Ctrl/Cmd + Enter` |
| 附件 | 本期不做 |
| 草稿 | 输入即存 localStorage（key = ticket id） |
| 关闭未发送 | 二次确认 |

### 操作与状态

| 操作 | 前置 | 结果 |
|---|---|---|
| 认领 | `assignee` 为空 | 变为当前坐席，状态 `claimed` |
| 发送 | 回复框非空 | 写 `messages`，状态 `claimed`，记 `audit_log` |
| 关单 | 已发送或手动 | `status=closed`，`resolution` 必填（≥10 字） |
| 转 L2 | — | `tags += escalate`，队列置顶 |
| 导出 HTML | — | 调 `exportToHtml` → MinIO → 下载 |

### 验收

- [ ] 1440×810 下「采纳」「发送」无需滚动即可见
- [ ] 采纳后回复框有内容且可编辑
- [ ] 关单必须填 resolution，否则按钮禁用
- [ ] 导出生成的 HTML 可离线打开，含时间轴与引用

## 6. A-P3 知识库

```
┌──────────────────────────────────────────────────────────────────────┐
│ 知识库                                    [+ 上传文档]  [重索引全部]    │
│ [全部 12][已索引 10][失败 2]        语言 ▾   产品线 ▾   搜索          │
├──────────────────────────────────────────────────────────────────────┤
│ 标题                    │ 语言│ 产品线  │ 页 │ 块 │ 状态   │ 操作      │
│ 阳台储能 600W 安装手册   │ DE  │ 阳台    │ 24 │ 86 │ 已索引 │ 预览 重索引│
│ 户储 5kWh 保修条款       │ NL  │ 户储    │ 6  │ 21 │ 已索引 │ 预览 删除  │
│ 微逆故障码表             │ 全部│ 阳台    │ 4  │ 32 │ 失败   │ 详情 重试  │
└──────────────────────────────────────────────────────────────────────┘
```

### 表格列

| 列 | 字段 | 说明 |
|---|---|---|
| 标题 | `documents.title` | 可编辑（行内） |
| 语言 | `documents.lang` | `zh/en/de/nl/es` 或「全部」 |
| 产品线 | `documents.product_line` | 阳台 / 户储 / 工商 |
| 页 | `documents.pages` | |
| 块 | `documents.chunk_count` | |
| 状态 | `documents.status` | pending/indexed/failed 徽章 |
| 操作 | — | 预览 / 重索引 / 删除 |

### 交互

| 场景 | 行为 |
|---|---|
| 上传 | 拖拽或点选，支持多选 PDF；单个 ≤20MB |
| 上传中 | 行内进度条，状态 `pending` |
| 失败 | 行内显示错误摘要，点开看全文；提供「粘贴文本入库」备选 |
| 预览 chunks | 侧滑面板，列出前 20 块，显示序号/页码/字数/前 120 字 |
| 删除 | 二次确认 + 输入文档名确认（防误删） |

### 验收

- [ ] 上传 PDF 后 90s 内 `indexed` 且 `chunk_count > 0`
- [ ] 失败可见具体原因
- [ ] 删除级联清 chunk，检索立即不再命中

## 7. A-P4 未命中池 / 草稿

双栏：左侧未命中问题列表，右侧草稿编辑器。

```
┌───────────────────────┬──────────────────────────────────────────────┐
│ 未命中问题 12          │ 草稿 · 第 3 条                               │
│ ┌───────────────────┐ │ 问题：Kunnen jullie korting geven?           │
│ │ Kunnen jullie...  │ │ 语言：NL                                     │
│ │ NL · 3 次 · 10-27 │ │ 答案：                                       │
│ ├───────────────────┤ │ ┌──────────────────────────────────────────┐ │
│ │ 保固包含電池嗎     │ │ │ 我们目前不提供折扣...                     │ │
│ │ ZH · 1 次 · 10-26 │ │ └──────────────────────────────────────────┘ │
│ └───────────────────┘ │ 状态：草稿                                   │
│                       │ [ 通过并入库 ]  [ 退回 ]                      │
└───────────────────────┴──────────────────────────────────────────────┘
```

### 流程

```
tickets(reason ∈ {no_citation, out_of_scope})
   │ 聚合相同 question（去重 + 计数）
   ▼
未命中池 ──[生成草稿]──▶ kb_drafts(status=draft)
   │                          │
   │                          ├─[通过]─▶ chunks 新增 + status=approved
   │                          └─[退回]─▶ status=rejected
   ▼
（已处理的问题从池里消失）
```

### 字段

| 字段 | 来源 |
|---|---|
| 问题 | `tickets.question` |
| 语言 | 会话语言 |
| 出现次数 | 按 question 去重计数 |
| 最近时间 | `max(created_at)` |
| 草稿答案 | 可手写，或用 AI 生成（基于相似文档）|
| 状态 | draft / approved / rejected |

### 验收

- [ ] 拒绝过的问题不再出现在池里
- [ ] 通过后同问题能被 `kb_search` 命中（10s 内生效）
- [ ] 5 语都能生成草稿

## 8. A-P5 数据看板

四列指标卡 + 两张图 + 一张表。

| 卡片 | 计算 |
|---|---|
| 今日会话 | `count(conversations) where date=today` |
| 独立解决率 | 无坐席回复且无 👎 且无工单 ÷ 今日会话 |
| 转人工率 | `count(tickets)` ÷ 今日会话 |
| 满意度 | 👍 ÷ (👍+👎) |

| 图 | 类型 | 说明 |
|---|---|---|
| 会话趋势 | 折线（7 天） | 会话数 + 转人工数双线 |
| 语言分布 | 横向条形 | 不用饼图（>5 类不适用） |

| 表 | 列 |
|---|---|
| 未命中 Top10 | 问题 · 次数 · 语言 · 最近时间 |

图表规范：网格线 `#E2E8F0`，数据线对比度 ≥3:1，图例常驻，hover 显示精确值，提供「查看数据表」切换（a11y）。

### 验收

- [ ] 数字来自实时聚合，非硬编码
- [ ] 空数据时显示「暂无数据」+ 说明，不显示空坐标框

## 9. 状态机

### 工单

```
        ┌──────────┐
  新建 ─▶│  open    │
        └────┬─────┘
             │ 认领
             ▼
        ┌──────────┐  转 L2   ┌──────────┐
        │ claimed  │─────────▶│ escalated│
        └────┬─────┘           └────┬─────┘
             │ 关单（需 resolution）  │
             ▼                      ▼
        ┌──────────────────────────────┐
        │           closed             │
        └──────────────────────────────┘
```
规则：`closed` 不可逆；`escalated` 可被 L2 再认领；SLA 到期不自动关闭，只置红。

### 草稿

```
draft ──通过──▶ approved ──▶ (写入 chunks)
  │
  └──退回──▶ rejected（终态）
```
