## 2. 指标定义（可测，无歧义）

| 指标 | 公式 | 通过线 |
|---|---|---|
| **hit@5** | `count(hit) / count(answered)` 其中 hit = top5 chunk 里存在 `doc_id == expect_doc_id` | ≥ 70% |
| **引用正确率** | `合法角标数 / 总角标数`，合法 = `n ∈ 本轮 kb_search 候选编号集合` | ≥ 85% |
| **拒答准确率** | `(should_refuse 且输出固定话术且新建 1 单) / (should_refuse 总数)` | ≥ 90% |
| **误拒率** | `(不该拒答却拒答) / (不该拒答总数)` | ≤ 10% |
| **多轮正确率** | 5 题中第二步问对的比例 | ≥ 60% |
| **首字 P95** | SSE 首 delta | < 3s |
| **单轮 P95** | 发送 → done | < 8s |
| **单会话成本** | 汇总 `cost_usd` ÷ 会话数 | < $0.03 |

### 2.1 不达标的处置顺序

1. 先看 hit@5 —— 检索不行，其他全是白搭
2. 再看守信阈值（`retrieval.min_score`）—— 太低导致误拒，太高导致答错
3. 再看分块 —— 500 字是否切断了语义
4. 最后才动 prompt

**禁止**在检索不达标时靠调 prompt 掩盖。

## 3. 跑分脚本（离线 Python）

`scripts/eval_run.py`：

```
读 qa_gold（30 条）
  → 逐条 POST /api/chat（SSE 消费）
  → 解析 citations 事件
  → 计算四指标
  → 写 eval_runs
  → 输出 markdown 报告到 docs/output/eval-{date}.md
```

要求：**可离线重跑**，同一数据集两次跑分差异 <5%（否则是随机性，不可信）。
