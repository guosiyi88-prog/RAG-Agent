# 04 · 数据库契约

> 文件：`sql/001_init.sql`（结构）+ `sql/002_seed.sql`（种子）。**不是容器启动时自动执行**：`make reset` / `make init` 把两个文件按顺序管道给 `data/scripts/db.sh psql`（`db.sh psql` 在容器内跑，SQL 只能走标准输入，带 `-f` 找不到路径）。
>
> §2 是权威内容；`sql/001_init.sql` 与它的差异只有三处，两边都在对应位置写明了原因：① 开头先 `drop` 本文件负责的全部对象（这个文件同时是 `make reset` 的重放脚本，语义必须是"恢复干净库"，`create ... if not exists` 会留下旧结构漂移和脏数据）；② 所有 `char(2)` 语言列都带 `check (lang in ('zh','en','de','nl','es'))`，不只 `documents.lang`；③ 已关闭工单的保护更严（`closed` 行的任何 UPDATE 都 `raise`）。

## 1. 设计要点

| 决策 | 原因 |
|---|---|
| 一库三用（元数据 + 向量 + 全文） | 少一个组件，少一类故障 |
| `chunks.embedding vector(1024)` + `tsv` 双索引 | 向量做跨语种，全文只做术语精确召回 |
| 时间一律 `timestamptz` | 欧洲/中国时区混用，必须存 UTC |
| 主键：业务表用 `uuid`，流水表用 `bigserial` | uuid 便于前端生成与去重，流水表要顺序 |
| 所有表带 `created_at default now()` | 排查问题必需 |
| 不建外键级联删除的地方显式写 `on delete` | 隐式行为是事故来源 |

-- ============================================================
-- 沃泰储能多语种客服 Agent · 初始化
-- 要求：PostgreSQL 16 + pgvector
-- ============================================================

create extension if not exists vector;
create extension if not exists pg_trgm;

-- ── 1. 文档 ──────────────────────────────────────────────
create table documents (
  id           uuid primary key default gen_random_uuid(),
  title        text not null,
  lang         char(2) not null check (lang in ('zh','en','de','nl','es')),
  product_line text,                          -- balcony|residential|cni
  bucket       text not null default 'wt-dev',   -- 与 data/.env.example 的 MINIO_BUCKET 一致
  object_key   text not null,
  sha256       text not null unique,
  pages        int,
  chunk_count  int not null default 0,
  status       text not null default 'pending'
               check (status in ('pending','indexed','failed')),
  err          text,
  created_at   timestamptz not null default now()
);
create index documents_lang_idx    on documents (lang);
create index documents_status_idx  on documents (status);

-- ── 2. 分块（检索核心） ──────────────────────────────────
create table chunks (
  id        bigserial primary key,
  doc_id    uuid not null references documents(id) on delete cascade,
  seq       int  not null,
  lang      char(2) not null,
  section   text,
  content   text not null,
  page      int,
  token_len int,
  embedding vector(1024),
  tsv       tsvector generated always as (to_tsvector('simple', content)) stored,
  created_at timestamptz not null default now()
);
create index chunks_emb_idx  on chunks using hnsw (embedding vector_cosine_ops);
create index chunks_tsv_idx  on chunks using gin  (tsv);
create index chunks_lang_idx on chunks (lang);
create index chunks_doc_idx  on chunks (doc_id, seq);

-- ── 3. 故障码（精确匹配，不经模型） ──────────────────────
-- 主键带 product_line：同一个码在不同产品线含义不同，不能只按 code 唯一
create table fault_codes (
  code         text not null,

  severity     text check (severity in ('info','warn','fatal')),
  desc_zh text, desc_en text, desc_de text, desc_nl text, desc_es text,
  act_zh  text, act_en  text, act_de  text, act_nl  text, act_es  text,

-- ── 4. 会话 ──────────────────────────────────────────────

  created_at     timestamptz not null default now(),

create index conversations_token_idx  on conversations (token_id);
create index conversations_created_idx on conversations (created_at desc);

-- ── 5. 消息 ──────────────────────────────────────────────

  intent          text,

-- ── 6. 引用快照 ──────────────────────────────────────────

-- ── 8. 工单 ──────────────────────────────────────────────
create sequence ticket_seq;

create or replace function gen_ticket_no() returns text as $$
  select 'WT-' || to_char(now(),'YYYY') || '-' ||
         lpad(nextval('ticket_seq')::text, 4, '0');
$$ language sql;

create table tickets (
  id         bigserial primary key,
  no         text unique not null default gen_ticket_no(),
  conv_id    uuid references conversations(id) on delete set null,
  message_id bigint,
  reason     text not null
             check (reason in ('no_citation','out_of_scope','low_conf','user_request')),
  question   text not null,
  requester  text,
  priority   text not null default 'normal'
             check (priority in ('low','normal','high','urgent')),
  status     text not null default 'open'
             check (status in ('open','claimed','escalated','closed')),
  assignee   uuid references staff(id) on delete set null,
  tags       text[] not null default '{}',
  due_at     timestamptz,
  resolution text,
  created_at timestamptz not null default now(),
  closed_at  timestamptz
);
create index tickets_status_idx   on tickets (status, due_at);
create index tickets_reason_idx   on tickets (reason);
create index tickets_assignee_idx on tickets (assignee);

-- closed 不可逆
create or replace function guard_ticket_status() returns trigger as $$
begin
  if old.status = 'closed' and new.status <> 'closed' then
    raise exception 'closed ticket is immutable';
  end if;
  if new.status = 'closed' and old.status <> 'closed' then
    new.closed_at := now();
  end if;
  return new;
end $$ language plpgsql;

create trigger trg_ticket_guard before update on tickets
  for each row execute function guard_ticket_status();

create table feedback (

-- ── 视图：未命中池 ───────────────────────────────────────
create view v_no_hit as
  select t.question,
         c.lang,
         count(*)          as hits,
         max(t.created_at) as last_at,
         (select count(*) from kb_drafts d
           where d.question = t.question and d.status <> 'rejected') as draft_count
  from tickets t
  left join conversations c on c.id = t.conv_id
  where t.reason in ('no_citation','out_of_scope')
    and t.status <> 'closed'
  group by t.question, c.lang
  order by hits desc, last_at desc;

**写入方与字段边界（容易被误读，写在这里）**

| 表 | 谁写 | 不写什么 |
|---|---|---|
| `documents` | `src/core/ingest.ts`：`title / lang / object_key / sha256 / status / chunk_count / pages / err` | **不填 `product_line`**：本期语料按语种分文件、不按产品线分目录，留空表示"通用于所有产品线"；路由与过滤只用 `lang` |
| `chunks` | 同一个事务里先 `delete ... where doc_id=$1` 再 100 条一批 `unnest` 插入 | `tsv` 是生成列，不出现在 INSERT 列表里；`embedding` 必须走 `$n::vector` |
| `fault_codes` | `corpus/fault_codes*.json`（文件名即路由）→ 一条 `on conflict (code, product_line) do update` 的 upsert | 不产生 `documents` 行、不产生 `chunks`；**不删**文件里没有的码（可能已被 `tickets`/`qa_gold` 引用） |

**`documents.status` 只有三态**：`pending`（已建行、还没写完块）→ `indexed`（块写完，`chunk_count`/`pages` 同步落库）或 `failed`（`err` 记错误码，**已写入的块不删**，下次重索引会先删）。没有第四态，也不允许 `status` 为空——质量检查靠这三态判断"是不是有文档没跑完"。

## 3. `sql/002_seed.sql`（权威内容）

> **`settings` 表与 `src/config.ts` 的关系（唯一口径）**：`config.ts` 里的 `RETRIEVAL_*` / `PARALLEL_LIMIT` 等常量是**默认值**；`settings` 表里同名的 `retrieval.*` / `par.slimit` 是**运行时覆盖**——启动时读一次，DB 有值的键覆盖内存值，没有的键用 `config.ts`。二期做后台调参只读写 `settings`，不改代码。**除这两个来源之外，任何地方都不得再出现这些参数的第三份值。**

## 4. 索引设计说明

| 索引 | 服务于 | 备注 |
|---|---|---|
| `chunks_emb_idx`（hnsw, cosine） | 向量召回 | `ef_search` 默认 40，召回 top20 足够 |
| `chunks_tsv_idx`（gin） | 术语精确召回 | 只对短查询有意义 |
| `chunks_lang_idx` | **语言过滤**（跨语种检索的关键） | 缺它会全表扫 |
| `tickets_status_idx (status, due_at)` | 队列按 SLA 排序 | 复合索引顺序不能反 |
| `messages_conv_idx` | 会话回放 | |
| `citations_msg_idx` | 详情页取引用 | |

## 5. 检索 SQL

**权威版本只有一处：`07-retrieval.md` §4.1（向量路）与 §4.2（全文路）。** 本节不再复制一份，避免两处漂移。

唯一的硬要求：两条 SQL 都**必须**带语言过滤，且写法一字不差：

```sql
where lang = any($2::char(2)[])       -- 语言过滤，禁止省略
```

> 省了会返回 5 个语言副本，RRF 后 top5 全是同义重复。`char(2)` 的 cast 不能省，否则 PG 会按 `text[]` 比较并放弃 `chunks_lang_idx`。

## 6. 查询约束

| 约束 | 原因 |
|---|---|
| 业务查询一律走参数化（`$1`），禁止字符串拼接 | SQL 注入 |
| 列表查询必须有 `limit`，默认 50，上限 200 | 防拖库 |
| 聚合查询在 SQL 里做，不在 Node 里 reduce | 数据量虽小，习惯要对 |
| 不 select `embedding` 列到业务代码 | 1 条 1024 float 序列化很慢 |
| `v_no_hit` 只读，不写入 | 视图 |
