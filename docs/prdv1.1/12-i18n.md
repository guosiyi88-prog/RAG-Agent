# 12 · 五语文案规范

> 文件：`src/static/i18n.json`。**中文为主源**，其余四语由主源生成并经校验。

## 1. 文件结构

```json
{
  "zh": { "chat.send": "发送", "chat.placeholder": "输入问题…" },
  "en": { "chat.send": "Send", "chat.placeholder": "Type your question…" },
  "de": { ... },
  "nl": { ... },
  "es": { ... }
}
```

**扁平 key**，不嵌套。五语的 key 集合必须**完全一致**。

---

## 2. 回落链

```
请求 lang → 若 key 缺失 → en → 若仍缺 → 返回 key 本身（开发期可见）
```

`GET /api/i18n/:lang` 在服务端做这一步 merge，前端只拿结果。

---

## 3. Key 命名规范

| 规则 | 例 |
|---|---|
| `模块.元素`，全小写，点分隔 | `chat.send` |
| 状态用 `状态.对象` | `status.searching` |
| 错误统一 `err.xxx` | `err.rate` |
| 占位符用 `{i}` `{n}` `{no}` | `cite.title = "引用 {i} / {n}"` |
| 不在 key 里写具体数字或语种 | ✗ `chat.send.de` |
| 错误统一 `chat.err.*` | `chat.err.rate` |

### 4.10 拒答话术（**已移出本文件**）

五语拒答话术的**唯一真源是 `src/core/refusal.ts` 的 `REFUSAL` 常量**（见 `06-agent.md` §5.3），由后端直接下发，不经模型、也不经 i18n 查表。

| 原有 key | 处置 |
|---|---|
| `refusal.zh/en/de/nl/es`（5 条） | **删除**。话术进常量，且不再带 `{no}`；工单号由 `refusal` SSE 事件单独给出，前端渲染工单卡 |

这样避免了「i18n.json 一份、refusal.ts 一份」的漂移，也让 G3 闸门（话术必须是模块级常量）可审。

## 6. 生成与校验流程

```
1. 人工定稿 zh（127 条，按 §4 的算式核对总数）
2. **拒答话术不进 i18n**：直接写 `src/core/refusal.ts` 的 `REFUSAL` 常量（5 语人工定稿，不机翻）
3. LLM 一次生成 en/de/nl/es（提示词附术语表）
4. 脚本校验（`scripts/check-i18n.ts`，必须全过）：
   a. key 集合与 zh 完全一致，且总数 == 127
   b. 无空值、无 null
   c. 无残留中文（de/nl/es 中不得出现 CJK）
   d. 长度 ≤ zh × 2.2（德语长词告警）
   e. 占位符 `{i}` / `{n}` / `{no}` / `{page}` / `{v}` 数量与 zh 一致
5. 人工抽检：de 全量（最高频市场），nl/es 各 20%
```

### 6.1 校验脚本（T09 实现）

```bash
npm run i18n:check
```

输出：
```
[ok]   keys: 127/127
[warn] de: chat.status.slow = 48 chars (zh 11) — 可能溢出
[fail] nl: cite.title 缺失占位符 {n}
```

任一 `[fail]` → 退出码 1。

## 7. 前端使用规范

| 场景 | 写法 |
|---|---|
| 静态文本 | `<span data-i18n="chat.send"></span>` |
| 占位符 | `<input data-i18n-ph="chat.placeholder">` |
| aria | `<button data-i18n-aria="a11y.send">` |
| 动态文本 | `t('chat.ticket.created', { no })` |

```js
function t(key, vars) {
  let s = i18n[key] ?? key;
  if (vars) for (const [k, v] of Object.entries(vars)) s = s.replaceAll(`{${k}}`, v);
  return s;
}
```

**禁止**在用户端 JS/HTML 里出现中文或英文字面量（除 `console.log` 与注释）。坐席端（`console.*`）不适用本条，见 `11-ui-console.md` 顶部例外。

## 8. 德语长词应对

德语 `Wechselrichterkonfiguration` 这类长词会撑破按钮。规则：

```css
.btn, .tab, .badge { min-width: 44px; overflow-wrap: anywhere; }
```

| 元素 | 处理 |
|---|---|
| 按钮 | 最小宽 44，允许换行两行 |
| Tab | 只放名词，不放句子 |
| Badge | 固定短词（见 §4.6 状态四项） |
| Toast | 单行，超出省略 |
