## 2. 登录门（gate）

首次打开显示 gate 卡片：输入**邮箱 + 口令**（口令 `type="password"`），提交到 `POST /api/auth/login`，
拿到的会话票据只存 `localStorage`（键仍是 `wt:console:token`，现在存的是票据而不是共享令牌），
**不写 URL、不进日志**。顶栏"退出登录"打 `POST /api/auth/logout` 并清本地票据。

页面加载时若已有票据，先打 `GET /api/console/me`：401 → 回 gate 重新登录；网络错 / 5xx →
**只读降级 + toast，不清票据**（D31，`boundary-change-R2.md` §5 第 6 条）。

票据缺失 / 失效时所有 `/api/console/*` 都是 401，前端表现为"gate 不通过"而不是"页面坏了"；
403（`FORBIDDEN`）只提示"权限不足"，**不清**登录态。

## 3. 队列

| 项 | 规则 |
|---|---|
| 轮询 | **5 秒**一次（`setInterval`），页面隐藏时不累积请求 |
| 筛选 | 状态 tabs（默认"待处理"= 除 `closed` 外全部）+ 原因下拉 + 关键词 `q`（≤100 字符） |
| 分页 | `size` 默认 20，上限 100；`page` 超界由**后端夹取**（前端不算边界） |
| 排序 | 后端固定按 SLA（`due_at` 升序，空截止排最后） |
| 选中 | 与详情路由同步（`#/tickets/:id`），刷新页面能回到同一单 |
| 空态 | "没有符合条件的工单" + 清筛选按钮 |
| **可见性** | **后端按角色过滤**（`09#03` 第三段，`boundary-change-R2.md` §7）：`agent` 只看自己的 + 未分配池，`lead`/`admin` 看全部。前端**不**按 `assignee_id` 自己过滤 —— 那等于把"看不到同事标题"变成一句只在界面上成立的话；`total` 已经是可见口径，直接用它算页数 |

**点开一张自己看不到的单**（比如别人发来的 `#/tickets/<id>` 链接）：详情回 **403**，
前端 toast"该工单已由他人处理"并留在队列，**不清**登录态。不是 404：锚点是我们自己下发过的，
说"这单没了"会让坐席反复刷新。


### 3.1 SLA 三档（纯逻辑 `console-sla.js`）

| 剩余 | 档位 | 显示 |
|---|---|---|
| `null`（无 `due_at`） | `none` | "无截止"，排最后，**不画成 0m** |
| `< 0` | `over` | `超时 2h 3m`（红） |
| `0 ≤ x < 3600` | `urgent` | `45m`（红加粗） |
| `≥ 3600` | `ok` | `3h 12m` |

**本地重算，不请求**：后端只给一次 `sla_seconds_left`，前端每 **30 秒**重算一次。
优先用 `due_at - now`（自愈休眠/改时钟/标签页冻结）；只有拿不到 `due_at` 时才退化成
`secondsLeft - elapsed`。`<60s` 单独显示 `Ns`（照规格写最后一分钟会显示 `0m`，坐席分不清"还有 40 秒"和"已归零"）。

## 4. 详情三栏

| 栏 | 内容 |
|---|---|
| 左 | 队列列表（保持可见，`j/k` 直接换单） |
| 中 | 会话消息：用户 / 助手交替；助手消息带工具名、引用数、时长；**`no_evidence` 为真时打"本轮无检索证据"标记** |
| 右 | 处置区：状态、认领、回复框、关单结论、复制单号/链接、引用弹窗、"翻译"（未开放）、**转 L2 / 转 FAQ 草稿（`09#06` 起是真动作）** |

**`no_evidence` 的判定在后端**：助手消息 + 未拒答 + 引用**实际行数**为 0。
前端不重算（用 `messages.citations_count` 会把"有引用但计数没刷上"误标成无证据）。

**引用弹窗**：点角标开模态，显示文档名、页码、语种、原文片段；Esc 关闭。

## 5. 处置动作与门槛

| 动作 | `data-act` | 规则 |
|---|---|---|
| 认领 | `claim` | 写 `assignee` = 当前登录坐席（服务端会话里的 `staffId`）。发给后端的是 `{status:"claimed"}`，**不带** `assignee_id` —— "给谁"由后端按会话决定，前端不参与 |
| 发送回复 | `send` | **发送前先置为已认领**（否则两个坐席各自"回复"同一单，谁也说不清谁在处理）；`closed` 单禁用 |
| 关单 | `close` | 必须填结论，**≥10 码点**（`RESOLUTION_MIN_CHARS`）；<10 时按钮禁用 + 显示还差几个字 |
| 复制单号 / 链接 | `copy-no` / `copy-link` | `navigator.clipboard`，失败回落 `execCommand` |
| 引用 | `cite` | 打开引用弹窗 |
| 返回 | `back` | 回队列（Esc） |
| 翻译 | `translate` | 走 501 端点，提示"本期未开放" |
| 转 L2（`09#06`） | `l2` | `POST /api/console/tickets/:id/escalate`：状态 → `escalated` + `tags += escalate`，队列置顶。已升级时按钮变「已升级 L2」并禁用 |
| 转 FAQ 草稿（`09#06`） | `faq` | 打开模态（问题预填本单、语言预填会话语言、答案 ≥10 码点）→ `POST /api/console/draft` 写一条待审 `kb_drafts`；主管在「FAQ 草稿」面板通过后才进索引 |

**派发口径（`09#03` 第三段，`boundary-change-R2.md` §7）**：把单给**他人**或**清空指派**是
`lead`/`admin` 的权力，`agent` 只能把单派给自己（= 认领）。判定在服务端
（`core/ticket-queue.ts` 的 `updateTicket`），`agent` 硬发会拿 **403 `FORBIDDEN`** —— 前端到那时
只提示"权限不足"，不清登录态。
**当前的界面上只有"认领"一个按钮**：选人下拉（派发 UI）是 `09#04` 的活，本卡只把后端约束做上。
所以现在"别人的单"只可能来自服务端派发或别的客户端，不是界面上能做出来的动作。


**关单结论按码点计数**（`Array.from(s).length`），与后端 `charCount` 同一口径——
用 `String.length` 时一个 emoji 算 2，会出现"前端说还差 1 字、后端说够了"。

**草稿按单隔离**：每张单一份草稿，**300ms 防抖**写 `localStorage`（`draft:<id>`），切单不串；
发送或关单后清空。

## 7. 数据与刷新

| 项 | 规则 |
|---|---|
| 轮询 | 队列 5s；详情不轮询（切单时拉一次，处置后局部替换那一行） |
| 乐观更新 | 处置成功后用响应里的 `ticket` 替换列表行，避免等下一轮轮询 |
| `changed` | 空数组 = 空操作（没写审计），前端不提示成功 |
| 错误 | 401 → 回 gate；403 → "权限不足 / 该工单已由他人处理"（**不清**登录态）；409 → "已关单，不能修改"；其它 → toast |

## 7A. 管理面板（`09#04` / `09#05`，`src/static/lib/console-admin-*.js`）

**一面板一文件、`await import()` 懒加载**（`console-admin-shell.js` 的 `PANEL_MODULES`）。面板契约：

```
mount(host, ctx) → unmountFn
ctx = { api(path, init?) → {ok, data?, error?}, role: "lead"|"admin", toast(msg), onSignOut() }
```

`api()` 已带会话票据；三种失败口径与主控制器一致（D31）：**401 → 票据清掉并弹回 gate**、
**403 → 只提示"权限不足"、留在当前面板**、**网络错 / 5xx → 只读降级 + toast，不清票据**。

| 面板 | 文件 | 主要动作 | 角色 |
|---|---|---|---|
| 故障卡 | `console-admin-faults.js` | 六列列表 + 四筛选 + 五语 Tab 表单（缺语红点）+ 发布/归档；`severity` 的"（未设置）"**显式发 `null`**（三态，省略 = 不改 = 假成功） | `lead` 编辑、`admin` 发布/归档 |
| 待审反馈 | `console-admin-reports.js` | `fault_reports` 列表 + 合并/忽略 | `lead` |
| 看板 | `console-admin-board.js`（+ `chart-svg.js`） | 数字卡片 + 四张图（量/分布/质量/知识库），没有数据的那张写"暂无数据"而不是画空白 SVG | `lead`/`admin` |
| 知识库 | `console-admin-kb.js` | 列表（标题/语言/状态/块数/版本/更新时间）+ 筛选 + 分页 + 新建/编辑（markdown）+ **重建轮询 1.5s（上限 ~60s）** + 回滚（`version>0` 才可用）+ 停用；后端 404 / 网络错 → 空态 + toast | `lead` 只读（写按钮禁用 + 说明"需要 admin"）、`admin` 全通 |
| 派发（详情内） | `console-view.js` 的 `dispatchHtml` + `console.js` 的 `dispatchTicket` | `GET /api/admin/staff` 取名单 → `<select>`（含"未分配"）→ `PATCH /api/console/tickets/:id` 的 `assignee_id`；选中值等于当前指派人**不发请求**，进行中禁用 | `lead`/`admin`（`agent` 只有"认领"） |

**前端隐藏不是安全措施**：真正的门在 `api/roles.ts` 的 `ROUTE_MIN_ROLE` + `requireRole`，
界面按角色藏/禁用只是省掉"点了才发现 403"。
