# 17 · 给接手 AI 的总纪律（as-built）

> 你正在接手一个**已经跑起来**的系统，不是从零开始。你的任务通常只有三种：改一处行为、加一个小功能、
> 修一个 bug。这三种都会撞上同一批硬约束——它们不写在类型里，只写在代码注释和这份文件里。

## 3. 十二条红线（违反任一条都会返工或被闸门拦）

| # | 不许 | 为什么 |
|---|---|---|
| 1 | 改 `docs/prdv1.1/` 一个字 | 它的价值就是冻结；改了就失去对照基线 |
| 2 | 给模型加白名单外的工具（尤其 `read`/`bash`/`edit`/`write`） | 客服 Agent 去读服务器文件 = 安全事故 |
| 3 | 去掉 `systemPromptOverride` 或让 `appendSystemPromptOverride` 返回非空 | 模型会退回"编码助手"人格 |
| 4 | 给 `session.agent.state.messages` 赋值 | 上下文权威只有 `SessionManager`，两套历史必打架 |
| 5 | 把 `model` 传成字符串 id | 会解析到别的 provider，症状是 401 而不是"模型不存在" |
| 6 | 把 `THINKING_LEVEL` 打开（非 `off`） | 首字延迟直接破 3s 预算 |
| 7 | 拿 RRF **原始分**和 `RETRIEVAL_MIN_SCORE` 比 | 原始分在 0.01 量级，结果是 **100% 拒答**且日志无异常 |
| 8 | 改最终分公式（`归一化 RRF × 余弦²`）不同时改 `14` §3 的断言 | 门禁会"照着旧口径通过" |
| 9 | 改 `i18n.json` 的 key 数却不改 `12` §1 的算式与 `check-i18n` | 127 是按 11 组算式断言的 |
| 10 | 让 `closed` 工单可被 UPDATE | 触发器硬拦是有意的：闭单后补写结论等于篡改历史 |
| 11 | 把内部接口失败改成 401/403 | 401 承认端点存在，会换来持续爆破 |
| 12 | 跑 `npm audit fix` 或并发跑 `npm test` | 前者把门禁变成改依赖；后者会互相污染计数 |

## 5. 十个最常见的坑（都真踩过）

1. **故障码快路在 `acquireSession` 之前**：挪到后面会让 `E03` 也装配一次会话（慢 300ms+）并占用池额度。
2. **`reply.hijack()` 之后状态码写不动**：任何需要 4xx/5xx 的失败都必须在开流前决定。
3. **`request.raw` 的 `close` ≠ 客户端断开**：`IncomingMessage` 的 `close` 在请求读完就触发；要听 `reply.raw`。
4. **`db.sh psql -f 路径` 找不到文件**：psql 在容器里跑，SQL 必须走标准输入。
5. **`grep -E '^DATABASE_URL' db.sh env` 一行都匹配不到**：输出是带缩进的表格，只能 `grep -oE` 抽片段。
6. **`EmbedError` 的维度错不是降级**：返回空会把数据事故伪装成"没搜到"，必须抛。
7. **判定"没检索"不能看候选是否为空**：低置信的一轮照样有 5 条候选；要看 `topScore`/`fallback`。
8. **同会话连发的"忙"不是故障**：`shouldEmitErrorFrame` 只在跨会话时为 true。
9. **`String.length` 不等于字数**：关单结论与 i18n 长度都按码点/显示宽度算。
10. **`minio-init` 退出了不是故障**：它是一次性容器。

## 6. 验收顺序（不要跳步）

```bash
npx tsc --noEmit                                   # 1. 类型
node --test --test-concurrency=1 tests/<改动相关>.test.ts   # 2. 单文件（快）
npm test                                           # 3. 全量串行（必须串行）
bash scripts/verify.sh --no-tests                  # 4. 八项（服务要起）
bash scripts/verify.sh                             # 5. 九项全量（提交前）
```

四件事缺一不算完成：**类型零错误 · 断言全过 · 无新增调试输出 · 无硬编码用户可见文案**。

## 8. 环境常识（省你十分钟）

- 所有 node 命令带 `--env-file-if-exists=.env`；`.env` 由 `./data/scripts/db.sh env` 派生，**不要手写连接串**。
- 数据层：`./data/scripts/db.sh up|down|destroy|check|psql|redis|logs`；`destroy` 要交互输入 `yes`。
- 三个端口：`8000`（应用）/ `5432`（pg）/ `6379`（redis）/ `9000-9001`（minio）。
- `pi:false` 是冷启动，不是故障。
- 会话池上限 5、闲置 10 分钟——门禁脚本自己会占一个槽位，`SESSION_BUSY` 先怀疑环境。

## 9. 你不该做的事（范围外）

不加登录体系、不加多租户、不加子 Agent / 计划模式 / MCP、不加前端构建链、不加 ORM、
不加 Jest/Vitest、不做持久化会话、不做 query 改写或翻译、不做语音与图片理解。
这些都在 `01` §5 的"明确不做"里，做了就是改范围——先改 `01`，再写代码。
